# 🔐 Enterprise Password Generator

> Architecting secure, unpredictable credentials through Python's standard libraries.

Built as part of the DecodeLabs Python Internship, this tool moves beyond basic scripting into real-world security thinking — generating strong, random passwords by combining letters and digits using Python's built-in modules.

---

## ⚡ Why This Project Matters
Every secure system relies on unpredictable credentials. This project bridges the gap between "writing code that works" and "designing tools that protect real users" — a core mindset in professional backend development.

---

## 🧩 Core Building Blocks

| Module | Purpose |
|--------|---------|
| `random` | Generates unpredictable, non-sequential values |
| `string` | Provides pre-built character sets (letters, digits) |

---

## ⚙️ How It Works
1. User specifies desired password length
2. Program pulls from a pool of letters + digits
3. `random.choice()` selects characters one at a time
4. Characters are joined into a final secure password

---

## 🚀 Run It Yourself
```bash
python password_generator.py
```

Enter your desired length when prompted — a fresh, random password is generated instantly.
