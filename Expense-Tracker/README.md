# 💰 Expense Tracker

A simple command-line application built in Python that tracks daily expenses. Users can continuously enter their expenses, and the program accumulates the total until they choose to stop.

---

## 📌 Features
- Enter multiple expenses continuously
- Automatically calculates running total
- Handles invalid input gracefully (defensive coding)
- Exit anytime by typing 'quit'

---

## 📚 Concepts Used
- Accumulator Pattern
- Type Conversion (int())
- Sentinel Values
- Exception Handling (try/except)
- While Loops

---

## 🎯 Learning Outcome
This project demonstrates how to build a program that processes continuous numerical input in real-time, handles invalid data safely, and maintains state (running total) across multiple iterations.

---

## 🛠️ Technologies Used
- Python 3

---

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file.
4. Enter expenses one by one, type 'quit' to see the total.
