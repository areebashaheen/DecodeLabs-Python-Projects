# 📝 To-Do List App

A simple command-line To-Do List application built in Python as part of my DecodeLabs Internship (Project 1).

---

## 📌 Features
- Add tasks to your list
- View all saved tasks with numbering
- Handles empty list gracefully
- Simple and user-friendly interface
- Runs continuously until the user chooses to exit

---

## 📚 Concepts Used
- Variables
- Lists
- User Input
- Conditional Statements (if/elif/else)
- Loops (while, for)
- enumerate() function

---

## 🎯 Learning Outcome
This project demonstrates how to use Python's core data structures to build a functional task management system, reinforcing fundamental programming logic like loops, conditionals, and list operations.

---

## 🛠️ Technologies Used
- Python 3

---

## ▶️ How to Run
1. Make sure Python is installed
2. Run the file using: python "To do list Python P1(decode).py"
