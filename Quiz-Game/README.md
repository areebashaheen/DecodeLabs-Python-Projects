# 🧠 General Knowledge Quiz

A command-line quiz game built in Python that asks 3 general knowledge questions, tracks the user's score, and displays the final result.

---

## 📌 Features
- Asks 3 general knowledge questions
- Case-insensitive and whitespace-tolerant answer checking
- Tracks score using an accumulator pattern
- Displays final score using f-string formatting

---

## 📚 Concepts Used
- Variables
- User Input
- String Methods (.strip(), .lower())
- Conditional Statements (if/else)
- Accumulator Pattern
- f-strings

---

## 🎯 Learning Outcome
This project demonstrates control flow and decision-making in programs, along with input sanitization techniques to handle real-world messy user input (extra spaces, inconsistent capitalization).

---

## 🛠️ Technologies Used
- Python 3

---

## ▶️ How to Run
1. Make sure Python is installed.
2. Run the Python file.
3. Answer each question as prompted.
4. View your final score at the end.
